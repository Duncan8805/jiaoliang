# 交糧帳

公糧過磅開單系統。輸入過磅重量、濕度、計劃／輔導公斤數，自動算出扣農會濕谷、工廠收購金額、烘乾費、袋費、運費和應付金額，可以列印傳票、查詢紀錄、匯出 Excel。

**離線可用**，平板、手機、電腦都能裝。

## 安裝到平板／手機

網址：<https://duncan8805.github.io/jiaoliang/>

第一次安裝要連網路，之後完全不用網路。

- **iPad / iPhone**：用 **Safari** 打開網址 → 點下方「分享」按鈕 → 「加入主畫面」
- **Android**：用 **Chrome** 打開網址 → 右上角「⋮」→「安裝應用程式」（或「加到主畫面」）
- **電腦**：用 Chrome 或 Edge 打開網址 → 網址列右邊的「安裝」圖示

裝好之後，從主畫面的「交糧帳」圖示打開。

## 資料存在哪裡

- 每台裝置都先存在自己的瀏覽器裡，**沒網路也能開單**。
- 在「後台設定 → 雲端同步」登入後，傳票、農民資料、設定會**自動同步到雲端和其他裝置**（有網路時自動上傳，畫面上方會顯示同步狀態）。
- 第一次登入：**主要裝置**按「確定」上傳現有資料；其他裝置按「取消」改用雲端資料。
- 單號全部連號。萬一兩台同時離線開到同一個號碼，後上傳的那張會自動改成下一個空號，畫面上方會提醒重印。
- 仍建議定期「後台設定 → 下載備份檔」。
- 雲端架構與設定見 [SYNC-DESIGN.md](SYNC-DESIGN.md)、[worker/](worker/)。

## 計算方式

| 項目 | 算法 |
|---|---|
| 貨實重 | 總重 − 空車 |
| 折算率、烘乾費 | 濕度四捨五入到整數，查「濕穀折算表」（後台可改） |
| 農會乾谷 | 計劃 + 輔導（手動輸入，乾穀 kg） |
| 扣農會濕谷 | 農會乾谷 ÷ 折算率（四捨五入） |
| 實重 | 貨實重 − 扣農會濕谷（由工廠收購） |
| 台斤 | 實重 ÷ 0.6 |
| 金額 | 台斤 × 單價 |
| 扣烘乾費 | 扣農會濕谷 × 烘乾費率 |
| 扣袋費 | 農會乾谷 × 袋費率（有勾「扣袋費」才扣） |
| **應付** | 金額 − 扣烘乾費 − 扣袋費（負數 = 農民應補） |
| 公糧款 | 計劃 × 計畫價 + 輔導 × 輔導價 + 袋費 |
| 運費 | 公斤數 × 運費率（只記錄，不從應付扣） |

金額小數一律無條件捨去。公糧價格、袋費、運費、折算表都在「後台設定」修改，改了只影響之後開的單。

## 更新系統（給維護的人）

1. 修改 `index.html`。
2. **把 `sw.js` 裡的 `CACHE` 版本號加 1**（例如 `jiaoliang-v1` → `jiaoliang-v2`），不然已安裝的平板不會更新。
3. commit 並 push 到 `main`，GitHub Pages 會自動發佈。
4. 平板連上網路打開一次 App，**關掉再開第二次**就是新版。
